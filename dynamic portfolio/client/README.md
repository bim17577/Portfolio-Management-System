# Dynamic Portfolio Client

This is the client-side of the Dynamic Portfolio project, built using HTML5, CSS, Bootstrap, and JavaScript. The project is structured to provide a clean and organized way to showcase your work and services.

## Project Structure

- **public/**: Contains the main HTML entry point.
  - **index.html**: The main HTML file that serves as the entry point for the application.

- **src/**: Contains the source code for the application.
  - **assets/**: Contains images and icons used throughout the project.
    - **images/**: Directory for image files.
    - **icons/**: Directory for icon files.
  - **components/**: Contains reusable HTML components.
    - **Header.html**: The header component of the application.
    - **Footer.html**: The footer component of the application.
    - **Navbar.html**: The navigation bar component of the application.
  - **pages/**: Contains the HTML structure for different pages of the portfolio.
    - **home.html**: The home page of the portfolio.
    - **about.html**: The about page of the portfolio.
    - **projects.html**: The projects page of the portfolio.
    - **services.html**: The services page of the portfolio.
    - **contact.html**: The contact page of the portfolio.
    - **portfolio.html**: The portfolio page showcasing projects.
  - **data/**: Contains JSON data for various pages.
    - **content.json**: JSON data for page content.
  - **services/**: Contains JavaScript files for handling services.
    - **contactService.js**: Functions for handling contact form submissions.
    - **userService.js**: Functions for user-related operations.
  - **App.js**: The main JavaScript file that initializes the application.
  - **index.js**: The entry point for the JavaScript application.

- **style.css**: The main stylesheet for the application.

- **package.json**: Configuration file for npm, listing dependencies and scripts.

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the client directory:
   ```
   cd client
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and go to `http://localhost:3000` to view the application.
